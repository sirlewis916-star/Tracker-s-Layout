# SpendWise Dashboard - Personal Budget Tracker

A responsive personal finance dashboard built with HTML5 and CSS3 for Week 3 Assignment.

## What I Built
SpendWise is a simple budget dashboard that shows total budget, total spent, remaining balance, and spending breakdown by category (Food, Transport, Entertainment, etc.). Inspired by tracking expenses in KSh.

It looks like a modern fintech app with a dark blue sidebar and card-based layout.
